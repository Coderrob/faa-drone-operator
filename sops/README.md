# Mission-Specific SOPs

These add domain controls to the common mission checklist. They do not replace
Part 107, an issued authorization/waiver, manufacturer instructions, professional
licensing, or client/site rules.

- [Photography and video](photography-video.md)
- [Mapping and photogrammetry](mapping-photogrammetry.md)
- [Infrastructure inspection](infrastructure-inspection.md)
- [Construction and real estate](construction-real-estate.md)
- [Agriculture](agriculture.md)
- [Public safety](public-safety.md)

Every SOP uses: define deliverable → identify added hazards/approvals → set data
quality and abort criteria → execute under remote-PIC authority → validate output
and retain records.
