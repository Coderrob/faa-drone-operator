# 14-Day Study Plan

Plan on 60–120 focused minutes daily. If chart reading and aviation weather are
new, repeat Days 5–8 rather than rushing.

| Day | Focus | Deliverable |
|---:|---|---|
| 1 | Certification path; read ACS introduction and appendices | IACRA/FTN created; exam rules understood |
| 2 | General rules and remote PIC authority | One-page limits/roles recall sheet |
| 3 | Operating rules; night; moving vehicle; carriage | 20 scenario questions reviewed |
| 4 | Operations over people; Remote ID; waivers | Category/RID decision tree from memory |
| 5 | Airspace classes and sectional legends | Identify airspace on 10 chart points |
| 6 | Airports, chart symbols, traffic patterns, authorization | Complete 10 airport/LAANC scenarios |
| 7 | METAR, TAF, weather services | Decode 10 reports without notes |
| 8 | Weather effects and density altitude | Explain five go/no-go weather scenarios |
| 9 | Loading, CG, performance, batteries | Solve loading/performance scenarios |
| 10 | Communications and airport operations | Phonetic alphabet and traffic-flow drill |
| 11 | Emergencies, ADM, CRM, physiology | Write mission abort criteria and responses |
| 12 | Maintenance and inspection; full ACS audit | Every tracker row rated 0–3 |
| 13 | Timed 60-question practice test | Error log grouped by ACS code |
| 14 | Targeted review and second fresh timed test | ≥85%; explain all misses |

## Deliberate-practice loop

For every missed or guessed question:

1. Record the ACS code and the mistaken reasoning.
2. Find the rule/concept in the primary FAA source.
3. Write the correct rule in your own words.
4. Create a different scenario that tests the same concept.
5. Retest it after 24 hours and again after three days.

Use `0 = unseen`, `1 = recognize`, `2 = explain`, and `3 = apply correctly in a
new scenario` in the tracker. Test readiness means all rows are at least 2 and
high-weight Operations topics are mostly 3.

## Exam-day strategy

- Arrive early with the exact identification PSI currently requires.
- Use the testing tutorial. Know how to flag a question and see time remaining.
- First pass: answer straightforward questions; flag time-consuming chart or
  computation items.
- Read units, altitude references, negatives, and words such as “unless,”
  “except,” and “most.”
- Use the supplied testing supplement carefully; confirm figure and legend.
- Eliminate answers that violate an explicit rule before comparing subtleties.
- Reserve 15–20 minutes to revisit flagged questions.
- Do not bring or use unauthorized notes/electronics. The proctor makes the final
  decision on permitted aids.

Afterward, keep the AKTR. Whether pass or fail, use every printed ACS deficiency
code to close knowledge gaps before operating.
