# Authoritative Source and Freshness Register

Review all `Critical` sources before each course release and at least quarterly.
Record a new “checked” date only after opening the source and comparing relevant
claims. Do not assume a stable URL means stable content.

## Facts intentionally marked as time-sensitive

- Testing and registration fees.
- IACRA, PSI, DroneZone, and LAANC screen names/workflow.
- Approved LAANC providers and facility availability.
- UAS Facility Map values, FRIA boundaries, TFRs, NOTAMs, and weather.
- FAA-accepted Remote ID and operations-over-people declarations.
- Course numbers/availability, ACS revision, rules, and guidance.
- Registration and certification processing times.

The documentation may state the checked value for orientation, but the user must
verify it at the authoritative source before relying on it.
